The shell can't tell developer code from user input.

What the developer wrote
$ ping -c 1 127.0.0.1

One command. The user's input sits where an argument belongs.

What the attacker types as "host"
$ ping -c 1 127.0.0.1; bash -c 'sleep 5'
◀ ping command ends at the semicolon ▶ attacker's new command starts here

The semicolon is a shell separator. Everything after it runs as a brand-new command, as if the attacker had logged into the server.
